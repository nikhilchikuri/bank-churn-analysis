# UK Bank Customer Churn Analysis

**Tools:** MySQL, Power BI
**Dataset:** 10,000 bank customers (Kaggle)

## Key Findings
- Overall churn rate: 20.37%
- Customers aged 45-59 had highest churn at 49.45%
- German customers churned at 32.44%
- Customers with 3-4 products had 83-100% churn rate
- Inactive members churned at 26.85%

## Recommendations
- Target retention campaigns at customers aged 45-59
- Review product bundling strategy
- Implement Germany-specific retention programme
- Launch re-engagement programme for inactive members
